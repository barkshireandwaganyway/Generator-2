Map Image Position

These controls only move/zoom the uploaded map image. Text, lines, circles, keys, and overlays stay in place.

Map Drawing Tools
Text Boxes

Default is the HRRR-style blue box, red outline, white text. Click a text box to edit/format it.

Color Key / Legend

Use the sliders to move and scale the key. You can still drag/rescale it by hand in the preview.

PNG Weather Overlays

To use saved icons, put PNGs in assets/overlays and add their file names to overlayLibrary in app.js.
